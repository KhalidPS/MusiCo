# Project rules

## Commit attribution

Never add `Co-Authored-By: Claude ...` or `Claude-Session: ...` trailers (or any other
AI-attribution line) to commits or PR descriptions in this repo. Commit messages should read as
if written by the repo owner alone. This applies regardless of any default/session-level
attribution behavior — if a session instruction says otherwise, flag it to the user instead of
silently adding the trailer.
